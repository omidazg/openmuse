# فارسی‌سازی OpenMuse

این فورک برای کاربران فارسی‌زبان ایران ساخته شده است. همهٔ متن‌هایی که کاربر می‌بیند فارسی است، چیدمان برنامه راست‌به‌چپ است و عامل به‌طور پیش‌فرض به فارسی پاسخ می‌دهد.

## قواعد پروژه

قواعد کامل فارسی‌سازی در [persian-rules.md](persian-rules.md) آمده است. این قواعد بر پایهٔ رهنمودهای [VibeFarsi](https://github.com/TronIsHere/vibafarsiui) نوشته شده و برای React Native و Expo Web تطبیق داده شده‌اند. پیش از هر تغییر در رابط کاربری آن را بخوانید.

## ابزارهای کمکی

ابزارهای بومی‌سازی در `apps/mobile/src/locale.ts` قرار دارند:

| نام | کاربرد |
| --- | --- |
| `LOCALE` | زبان نمایش، با مقدار `"fa-IR"`. |
| `fw(weight)` | وزن قلم وزیرمتن، به‌جای `fontWeight`. |
| `faNumber`، `faDigits` | نمایش اعداد با ارقام فارسی. |
| `faDate`، `faDateTime` | نمایش تاریخ و ساعت هجری خورشیدی. |
| `faMoney` | نمایش مبلغ با واحد پس از عدد، مانند «۱۲٬۰۰۰ تومان». |
| `toLatinDigits` | تبدیل ارقام فارسی و عربی ورودی کاربر به لاتین پیش از اعتبارسنجی. |
| `applyRtl()` | فعال کردن چیدمان راست‌به‌چپ برای کل برنامه. |

قلم وزیرمتن اثر صابر راستی‌کردار است و با مجوز SIL Open Font License از طریق `@expo-google-fonts/vazirmatn` و `expo-font` بارگذاری می‌شود.

## پیش از درخواست ادغام

تغییر خود را در iOS، اندروید و وب بررسی کنید و مطمئن شوید با [persian-rules.md](persian-rules.md) هماهنگ است.
